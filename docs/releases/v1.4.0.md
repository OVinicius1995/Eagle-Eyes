# Eagle Eyes 1.4.0

Clique na câmera ou pressione **Ctrl+Shift+S** para copiar um print. Durante a gravação, o print usa a região gravada. Clique na miniatura para marcar a imagem com o lápis, trocar a cor ou desfazer um traço. **Salvar print** salva o PNG e copia a versão editada. Se você deixar a miniatura fechar, o original é salvo automaticamente.

Na barra de gravação, use o lápis para destacar pontos em vermelho, amarelo ou azul. Cada traço desaparece três segundos depois de soltar o mouse. Clique novamente no lápis para voltar a interagir com a tela. Passe o mouse sobre a câmera, o lápis ou as cores para ver as dicas.

Baixe o instalador Windows x64 abaixo. Se já usa a versão 1.3.0 ou 1.3.1, abra **Configurações → Verificar atualizações → Atualizar**. O instalador inclui o runtime .NET e precisa de internet para preparar o FFmpeg.
