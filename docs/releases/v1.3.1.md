# Eagle Eyes 1.3.1

A gravação passa a usar Desktop Duplication nos monitores compatíveis para reduzir a piscada do ponteiro. O cursor continua incluído no vídeo. Quando o Windows ou o FFmpeg não consegue iniciar esse método, o Eagle Eyes usa a captura anterior. Em alguns equipamentos, o cursor parado pode aparecer pela primeira vez quando o mouse se move.

Para atualizar a partir da 1.3.0, abra Configurações, clique em **Verificar atualizações** e depois em **Atualizar**. O aplicativo verifica o download e inicia o instalador quando está ocioso. Ao concluir, abra o Eagle Eyes pelo menu Iniciar.
